# CARES — U.S. Army SBIR Phase I AI Engineering Case Study

**Canine Assessment Remote Evaluation System (CARES)**  
**Program:** U.S. Army SBIR Phase I, Topic A254-P001  
**Role:** Principal Investigator / Chief AI Engineer, Corusen LLC

## Project context

CARES investigated a contact-free, multi-sensor AI monitoring approach for working dogs in kennel environments. The engineering goal was to analyze sensor-derived spatial and temporal patterns to support monitoring of normal and potentially abnormal activity.

## Engineering responsibilities

- Led the AI technical approach and served as Principal Investigator for the Phase I effort.
- Worked across sensor-system design, modeling architecture, technical planning, and reporting.
- Designed the AI Monitoring Module around a hybrid **CNN–LSTM** approach: convolutional feature extraction for spatial patterns and recurrent modeling for temporal dynamics.
- Considered event classification, latency, on-device inference, and dashboard integration in the system design.
- Supported the successful SBIR Phase I proposal, technical deliverables, and project coordination.

## Technical areas

**Multi-sensor monitoring · Deep learning · CNN–LSTM · Temporal pattern recognition · Anomaly/event detection · Edge inference considerations**
